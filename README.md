# Banco Solidario Puntos — demostración

Sitio de demostración compilado (Angular 22). Funciona completo en el navegador con un servidor simulado: los datos se guardan en el almacenamiento local de tu navegador y no se envía nada a ningún servidor.

- **Sitio del participante:** ingresa con cualquier documento (por ejemplo `1712345678`) y cualquier código de 6 dígitos (por ejemplo `123456`). En el **primer ingreso** aparece la aceptación de Términos y condiciones y de la Política de privacidad (uso y tratamiento de datos); solo se pide esa vez.
- **Panel de administración:** `/admin` (usuarios de ejemplo por rol).

Esta carpeta solo contiene el resultado compilado; el código fuente está en un repositorio privado.
